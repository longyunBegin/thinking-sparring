# 思考陪练（Thinking Sparring）

一个只挑刺、不附和的思考陪练。把一个观点丢进来，它站在反面拆你的前提，直到观点经得起推敲，或者你发现它站不住。

适用于投资判断、内容选题、一人公司方向、任何重要决定。

## 四步流程

1. **说清观点**：用一句话写下你相信什么，越具体越好（有对象、有时间、可证伪）。
2. **拆前提**：找出这句话背后藏着的 3–5 个假设。
3. **逐个攻击**：每个假设都问：证据是什么？反例是什么？如果它错了会怎样？
4. **留下结论**：哪个前提最牢、哪个最脆弱、看到什么信号说明你错了、下一步做什么。

## 怎么用

- **Grok Bot 里**：打开「思考陪练」助手直接聊；其他助手里说「陪练一下这个观点」也会走同一套流程。
- **任何 AI 里**：把 [`PROMPT.md`](./PROMPT.md) 的内容粘进去当系统提示词，就能在 ChatGPT、Claude、Grok 等任何对话里用。
- **自己写**：复制 [`template.md`](./template.md) 填空。

## 决策档案

每次陪练的结论存在 [`decisions/`](./decisions/)，一份一个文件，文件名 `YYYY-MM-DD-主题.md`。过一段时间回来对照结果，看看自己哪些判断对了、哪些前提总是被高估。

> 这是公开仓库：不要写入账户、持仓金额、密码等私人信息。内容仅为个人思考记录，不构成任何投资建议。
